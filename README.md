# B站音乐 Mini

独立的 Chrome Manifest V3 开发版：将用户有权播放的 B 站视频音轨放入 offscreen 后台播放器。已实现 BVID/链接解析、WBI 签名、后台音频、基础控制、popup 长连接、播放地址刷新、分 P 队列、本地与账号历史、站内搜索、热门与主页推荐、音乐/直播/番剧/漫画/专栏相关内容、静音同步视频、B站浏览器登录态、可分页特别关注和只读收藏夹。

## Mini 家族

Mini 家族为不同音乐平台提供轻量浏览器播放器：

- [Netease Music Mini](https://github.com/vaeccc/netease-music-mini)：网易云音乐歌单、搜索与后台播放。
- [Bili mini](https://github.com/vaeccc/Bili-mini)：把有权访问的 B 站视频音轨作为后台音乐播放。
- [QQ Music Mini](https://github.com/vaeccc/qq-music-mini)：QQ 音乐曲库、搜索与后台播放。

## 本地加载

1. 打开 `chrome://extensions/`。
2. 启用“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录。
5. 点击工具栏中的扩展图标，从主站推荐、收藏夹或历史记录中选择视频播放。

## 内容边界

仅播放用户在 B 站正常有权访问的内容；不提供会员、地区、版权或其他访问限制的绕过能力。

## 已知限制

- popup 现在会按后台音频进度加载一条静音、低带宽优先的视频轨；关闭 popup 会立即释放该视频轨，后台音频不受影响。
- 播放 CDN 地址会过期，扩展不保存直链，并在错误或预定刷新时重新解析。
- 为兼容 B 站 CDN 的防盗链校验，扩展仅对 B 站媒体 CDN 请求设置 `Referer: https://www.bilibili.com/`；不会修改其他网站的请求。
- 账号功能复用浏览器中已登录的 B站会话；扩展不读取、保存或上传 Cookie 值。
- 未登录时历史记录保存在本地浏览器中，最多保留最近 50 个播放项；登录 B 站后，历史页优先读取 B 站账号观看记录，并支持继续下滑分页加载。
